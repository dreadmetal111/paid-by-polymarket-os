# Beta Feedback

Purpose:

Collect simple private feedback from trusted public beta users without adding accounts, payments, or a public feedback wall.

## What The Form Collects

- Optional `rating` from 1 to 5.
- Required `message`, up to 2000 characters.
- Optional `email`.
- Optional `source`, defaulting to `public-beta`.
- `created_at` timestamp.

## What Is Intentionally Not Collected

- IP addresses.
- User agents.
- Cookies.
- Wallet addresses.
- Admin secrets.
- Supabase service role keys.
- Discord webhook URLs.
- Acer/private infrastructure details.

Feedback is not displayed publicly.

## Supabase SQL

Run this in the Supabase SQL Editor:

```sql
create table if not exists public.beta_feedback (
  id bigint generated by default as identity primary key,
  rating integer,
  message text not null,
  email text,
  source text,
  created_at timestamptz not null default now()
);

create index if not exists beta_feedback_created_at_idx
  on public.beta_feedback (created_at desc);
```

## JSON Fallback

If Supabase is not configured or cannot save feedback, the backend stores feedback locally in:

```text
data/beta-feedback.json
```

This file is ignored by Git.

## PowerShell Test Command

```powershell
$body = @{
  rating = 5
  message = "The market cards helped me find active markets faster."
  email = ""
  source = "manual-test"
} | ConvertTo-Json

Invoke-RestMethod `
  -Method Post `
  -Uri "https://paid-by-polymarket-os.onrender.com/api/feedback" `
  -ContentType "application/json" `
  -Body $body
```

## Admin Status

The protected admin status endpoint returns aggregate feedback status only:

- `feedback.count`
- `feedback.latestFeedbackAt`
- `checks.feedbackStorage`

Do not paste private feedback text, real emails, or raw submissions into public chats, screenshots, or logs.
