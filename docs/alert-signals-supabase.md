# PBP Alert Signals Supabase Setup

This document sets up the Render-side foundation for a safe public alert feed.
Alert signals are sanitized public-safe records that can later be pushed from the
Acer alert worker into the public Paid by Polymarket OS Render app.

Do not expose secrets, Discord webhook URLs, Acer Node IPs, admin routes,
waitlist emails, Supabase service role keys, or private infrastructure details.

## Supabase SQL

Run this SQL in the Supabase SQL Editor for the same project used by the waitlist.

```sql
create table if not exists public.alert_signals (
  id bigint generated by default as identity primary key,
  alert_type text not null,
  market_question text not null,
  reason text,
  severity text,
  source text,
  created_at timestamptz not null default now()
);

create index if not exists alert_signals_created_at_idx
  on public.alert_signals (created_at desc);
```

## Render Environment Variable

Add this environment variable to the Render service:

```text
PBP_ALERT_INGEST_SECRET=paste-a-long-random-secret-here
```

The app also uses the existing Supabase environment variables:

```text
SUPABASE_URL
SUPABASE_SERVICE_ROLE_KEY
```

Never put `PBP_ALERT_INGEST_SECRET` or `SUPABASE_SERVICE_ROLE_KEY` in frontend
code, public docs, screenshots, chats, or logs.

## PowerShell Test: POST /api/internal/alerts

Set the ingest secret only in your local PowerShell session:

```powershell
$env:PBP_ALERT_INGEST_SECRET = "paste-your-ingest-secret-here"
```

Send one safe manual test alert:

```powershell
$headers = @{
  Authorization = "Bearer $env:PBP_ALERT_INGEST_SECRET"
}

$body = @{
  alertType = "volume_liquidity_spike"
  marketQuestion = "Will example market happen?"
  reason = "Volume increased quickly."
  severity = "high"
  source = "manual-test"
} | ConvertTo-Json

Invoke-RestMethod `
  -Method Post `
  -Uri "https://paid-by-polymarket-os.onrender.com/api/internal/alerts" `
  -Headers $headers `
  -ContentType "application/json" `
  -Body $body
```

Expected result:

```json
{
  "ok": true,
  "status": "created",
  "storageMode": "supabase",
  "message": "Alert signal stored."
}
```

## PowerShell Test: GET /api/alerts/recent

This endpoint is public because it only returns sanitized alert signals.

```powershell
Invoke-RestMethod `
  -Method Get `
  -Uri "https://paid-by-polymarket-os.onrender.com/api/alerts/recent" |
  ConvertTo-Json -Depth 5
```

Expected shape:

```json
{
  "ok": true,
  "alerts": [
    {
      "alertType": "volume_liquidity_spike",
      "marketQuestion": "Will example market happen?",
      "reason": "Volume increased quickly.",
      "severity": "high",
      "createdAt": "ISO_TIMESTAMP"
    }
  ],
  "generatedAt": "ISO_TIMESTAMP"
}
```

## Safety Notes

- Do not connect the public Render app directly to Acer Node.
- Do not expose Discord webhook URLs.
- Do not expose Acer Node IPs, Tailscale addresses, or local network details.
- Do not expose waitlist emails or `/api/admin/waitlist` output.
- Do not expose `PBP_ADMIN_SECRET`, `PBP_ALERT_INGEST_SECRET`, or
  `SUPABASE_SERVICE_ROLE_KEY`.
- Only send sanitized public-safe alert text into `POST /api/internal/alerts`.
