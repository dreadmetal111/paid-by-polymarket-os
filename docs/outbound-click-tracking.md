# Outbound Click Tracking

Purpose:

Track privacy-safe clicks from Paid by Polymarket OS market cards to Polymarket. This helps show that PBP is routing real market-discovery intent toward Polymarket without collecting personal user data.

## What Is Tracked

The public site sends a lightweight event when a visitor clicks a primary market CTA such as `View on Polymarket`.

Tracked fields:

- `market_id`
- `market_slug`
- `market_question`
- `market_url`
- `source_section`
- `cta`
- `created_at`

These fields describe the market and the page section where the click happened. They do not identify the visitor.

## What Is Intentionally Not Tracked

Do not collect or store:

- Emails
- Wallet addresses
- IP addresses
- User agents
- Cookies
- Admin secrets
- Supabase service role keys
- Render ingest secrets
- Discord webhook URLs
- Acer/private infrastructure details

The frontend call is fire-and-forget. If click tracking fails, the user should still open Polymarket normally.

## Supabase SQL

Run this in the Supabase SQL Editor when durable click tracking is needed:

```sql
create table if not exists public.outbound_click_events (
  id bigint generated by default as identity primary key,
  market_id text,
  market_slug text,
  market_question text,
  market_url text,
  source_section text,
  cta text,
  created_at timestamptz not null default now()
);

create index if not exists outbound_click_events_created_at_idx
  on public.outbound_click_events (created_at desc);
```

## Local JSON Fallback

If `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` are not configured, the backend stores events in:

```text
data/outbound-click-events.json
```

This file is ignored by Git.

## PowerShell Test Command

```powershell
$body = @{
  marketId = "example-market-id"
  marketSlug = "example-market"
  marketQuestion = "Will example market happen?"
  marketUrl = "https://polymarket.com/event/example-market"
  sourceSection = "top-opportunities"
  cta = "view-on-polymarket"
} | ConvertTo-Json

Invoke-RestMethod `
  -Method Post `
  -Uri "https://paid-by-polymarket-os.onrender.com/api/events/outbound-click" `
  -ContentType "application/json" `
  -Body $body
```

## Admin Status Check

The protected admin status endpoint returns aggregate click status only:

- `outboundClicks.count`
- `outboundClicks.latestClickAt`
- `checks.outboundClickStorage`

It does not expose a public click event list.

## Builder-Readiness Value

Outbound click tracking helps demonstrate that Paid by Polymarket OS is a discovery and routing layer:

- Users scan active markets in PBP.
- Users click into Polymarket from the primary CTA.
- Admin status can show aggregate routing activity without private user data.
- The product story becomes easier to explain for Builder Program readiness.
